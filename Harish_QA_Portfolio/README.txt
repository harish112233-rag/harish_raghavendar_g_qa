Harish Raghavendar G — QA Game Tester Portfolio
================================================

HOW TO RUN
Just double click index.html and it opens in your default browser.
No install, no server, no build step needed.

FILES
index.html   Page structure and content only
style.css    All visual design (fonts, colors, layout, responsive rules)
script.js    All interactivity (rotating terminal text, mobile menu,
             project filters, live bug-report ticket generator, scroll-to-top)

EDITING
- Text and content changes go in index.html
- Colors, spacing, fonts, and responsive breakpoints go in style.css
  (all the theme colors are defined once at the top under :root)
- Behavior and interactivity go in script.js

DEPLOYING
This is a fully static site. You can:
- Open it directly from your computer
- Upload all three files (plus this README if you like) to any static
  host: GitHub Pages, Netlify, Vercel, etc. Just make sure index.html,
  style.css, and script.js stay in the same folder.
